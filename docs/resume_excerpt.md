# 简历条目草稿

**ReelPilot：面向文娱素材的多模态检索与可恢复剪辑 Agent**　个人项目

技术：Python / Qwen3-VL-Embedding / Qwen3 / FastAPI / SQLite / FFmpeg

- 构建带来源时间戳的多模态素材管线，结合 Whisper 词级转写与窗口截帧，建立画面、对白、联合内容三种向量索引，支持按检索目标选择通道及 BM25/RRF 对照。
- 基于 Qwen3 与 JSON Schema 约束解码拆解创意需求，设计 EditPlan 中间表示与预算约束 Beam Search，在时长、片段数、来源区间及不重叠约束下生成剪辑计划，经独立验证后调用 FFmpeg 完成媒体执行。
- 实现 SQLite 幂等请求、所有权租约、阶段日志与哈希验证恢复；渲染后受控异常实验中复用已完成产物，完成 41 项契约、竞争、恢复及真实媒体/API 测试。

按简历篇幅可补充：在两份公开素材、15 个场景意图的 30 条中英文开发查询上比较五种检索方案，画面向量 MRR@10 为 0.932，联合向量为 0.791；根据模态噪声分析调整默认路由。

指标必须保留「开发查询」范围，不能写成线上准确率、独立测试集结果、企业实习经历或模型训练成果。项目由 AI 编程工具辅助实现，投递前应能解释代码中的约束编译、索引一致性、恢复机制和失败案例。
