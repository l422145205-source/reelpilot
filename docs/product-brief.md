# 素材检索与剪辑产品说明

## 使用场景

目标用户假设为游戏宣传素材制作人员、视频内容创作者及素材编辑。其任务是根据一份简短创意找到若干相关画面或对白，并组织成可核对来源的短片。当前项目没有进行独立用户访谈或商业环境验证，以下是为原型定义的需求与验收标准。

## 功能范围

1. 查看已导入素材及授权信息，按素材范围检索画面或对白。
2. 通过自然语言需求生成检索目标，或直接填写明确目标。
3. 设置总时长上限、片段数及同一素材内的时间顺序。
4. 查看候选片段与来源时间，生成剪辑并导出 EditPlan JSON。
5. 检查执行阶段，保留失败原因，恢复时校验并复用已有产物。

界面提供候选预览、任务事件和剪辑时间轴。输出作为人工审片的候选成片，当前版本未实现逐帧拖拽剪辑、完整数字音频工作站、角色一致性生成、配音、版权判定或商业发布管理。

## 验收与异常分支

| 场景 | 预期行为 |
|---|---|
| 没有可匹配字幕 | 返回空检索结果，不用任意片段填充 |
| 未配置模型却选择语义模式 | 明确报错，提示需要模型和索引 |
| 模型输出额外操作字段 | 拒绝解析 |
| 时长、覆盖和不重叠条件无法同时满足 | 不执行剪辑，返回具体错误 |
| 相同任务 ID 提交不同需求 | 返回冲突 |
| 输出在完成后被破坏 | 恢复执行重新渲染 |
| 旧 worker 在租约过期后返回 | 阻止其发布产物 |
| 语义相关但不符合创意 | 由用户审片发现；检索分数不作为正确性承诺 |

## 后续验证

后续应邀请真实创作者完成固定素材任务，记录首次定位时间、人工改动片段数、执行失败和人工验收结果。上线后的使用量、节省工时、留存和转化均不在当前成果中。优先改进镜头边界、动作定位和对白完整性，并用新的独立标注素材验证改进。
